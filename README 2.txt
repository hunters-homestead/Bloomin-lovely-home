BLOOMIN LOVELY HOME — VERSION 2

This is a personal iPhone-friendly web app/PWA.

Version 2 additions:
- Installable PWA manifest and iPhone icon
- Offline app shell
- Daily / weekday / weekly / fortnightly / monthly repeat choices
- Optional task due dates
- Weekly activity/date view
- Individual kids and kids' points
- Reward history
- Export/import backup
- Editable work, home, kids, shopping and activities
- Earthy calm colour palette

IMPORTANT:
The app data is stored locally in the browser/device. The backup feature lets you export a JSON copy.
For a true iPhone Home Screen app, publish the folder to an HTTPS web address (GitHub Pages is one option), open that address in Safari, then Share > Add to Home Screen > Open as Web App > Add.
